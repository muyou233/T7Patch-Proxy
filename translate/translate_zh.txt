# T7Patch UI 翻译词库
# version: 2026-09-18a
# 匹配规则（实现见 src\translate.cpp）：
#   - 引擎会把一条 UI 文本拆成若干「片段」分别送出（片段之间是控制字节），本文件按片段匹配
#   - 键里的 '*' 匹配任意文本（模板条目，见文件末尾）；值里的 '*' 按顺序填回捕获到的原文
#   - 键以 '~' 开头 = 可组合片段：只有标记过的条目才允许在更长的片段*内部*被替换（第三通道）
#   - 命中顺序：精确条目 → 模板（'*' 更少者先试）→ 片段（键更长者先试）
#   - 未标记的条目**永远**只在整段相同时命中，所以短词（menu/play/rogue）不会误伤玩家名
#   ⇒ 改完保存即生效（约 2 秒内热加载），不用重启游戏
